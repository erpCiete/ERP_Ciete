# Materiales de referencia CIETE

> **Documento vivo.**

Esta carpeta contiene materiales originales o auxiliares entregados por CIETE o usados durante el analisis funcional del ERP.

Pueden incluir:

- PDFs de apoyo.
- Excels de referencia.
- Documentos recibidos del cliente.
- Archivos usados para revisar casos reales, demos o criterios de trabajo.

Estos materiales son referencia y evidencia de trabajo. No son la fuente de verdad funcional vigente.
