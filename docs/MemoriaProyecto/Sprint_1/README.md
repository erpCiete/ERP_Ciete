# Sprint 1 - Desarrollo inicial

##  Objetivo del sprint
El objetivo de este sprint ha sido establecer la base estructural del frontend, permitiendo disponer de una aplicación funcional sobre la que continuar el desarrollo en siguientes iteraciones.

---

##  Tareas realizadas
Durante este sprint se han llevado a cabo las siguientes tareas:

- Configuración y puesta en marcha del proyecto en React  
- Definición de variables CSS globales  
- Implementación de la pantalla de login funcional  
- Desarrollo del sidebar (menú lateral)  
- Creación del dashboard base  
- Configuración de rutas principales de la aplicación  
- Inicio de la implementación de tema claro/oscuro  
- Inicio del soporte multilenguaje  

---

## Organización del equipo
El trabajo se ha distribuido entre los distintos miembros del equipo, asignando responsabilidades específicas en función de cada área del frontend (login, dashboard, navegación, estilos y documentación).

En particular, se ha realizado la preparación documental del proyecto, organizando la estructura de carpetas y recopilando evidencias visuales (capturas) para su inclusión en la memoria.

---

##  Resultado
Como resultado de este sprint, se dispone de una aplicación base funcional que incluye login, dashboard y navegación mediante sidebar, así como una primera aproximación a temas visuales y soporte multilenguaje.

Esto permite continuar con el desarrollo del sistema en los siguientes sprints.
