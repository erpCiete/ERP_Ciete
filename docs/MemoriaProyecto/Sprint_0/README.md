# Sprint 0 - Preparación del proyecto

##  Objetivo
El objetivo del Sprint 0 ha sido preparar el entorno de trabajo y definir la estructura inicial del proyecto, estableciendo las bases necesarias para el desarrollo posterior.

---

##  Tareas realizadas
- Creación del repositorio del proyecto en GitHub  
- Definición de la estructura inicial de carpetas  
- Selección de tecnologías a utilizar (frontend y backend)  
- Configuración del entorno de desarrollo  
- Organización inicial del equipo y reparto de tareas  

---

## Tecnologías utilizadas
- Laravel 12  
- PHP 8.2  
- Inertia.js 2 + React 18  
- Tailwind CSS 3 + Vite 6  
- SQLite (por defecto en local) y soporte para MySQL  
- Control de versiones: Git y GitHub  

---

## Estructura inicial del proyecto
Se ha definido una estructura base separando frontend y backend para facilitar la escalabilidad y el mantenimiento del proyecto.

---

##  Problemas encontrados
- Configuración inicial del entorno  
- Dudas en la organización del proyecto  

---

##  Soluciones aplicadas
- Revisión de documentación oficial  
- Ajustes en la configuración del entorno  

---

##  Resultado
Se ha conseguido dejar preparado el entorno de desarrollo y la base del proyecto, permitiendo comenzar el desarrollo funcional en el siguiente sprint.
