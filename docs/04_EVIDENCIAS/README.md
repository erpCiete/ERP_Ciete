# Evidencias ERP CIETE

Carpeta reservada para evidencias de trabajo y validacion:

- `tests/`
- `capturas/`
- `builds/`
- `validaciones_manuales/`

Reglas:

- Conservar evidencias unicas que respalden validaciones o KOs.
- No mover ni borrar evidencia si es la unica prueba disponible.
- Si una evidencia se reemplaza por otra, dejar referencia al documento nuevo.
